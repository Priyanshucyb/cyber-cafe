# Source audit

The entire supplied HTML was reviewed: head and metadata, all CSS, markup, and all script sections.

## Retained visual identity

- Warm cream `#F1ECDF`, ink `#17150F`, brass, and deep green.
- Space Grotesk display typography, JetBrains Mono utility labels.
- Large uppercase hero, tight tracking, strong editorial hierarchy.
- SVG connected-line visual language and perspective floor.
- Hard-offset button shadows and pill outlines.
- Dark final contact composition, outline paths and numbered sections.
- User-selectable light/dark themes.

## Changes for the client brief

- Rebuilt into typed React components with centralized business configuration.
- Replaced agency workflow storytelling with cafe contact / visit planning.
- Custom workstation illustration retains the line-and-node visual direction; it is not presented as a real photograph.
- Open service directory rather than a uniform icon-card grid.
- Practical visit guide and illustrated location panel, rather than invented trust claims.
- Sticky mobile contact bar, accessible menu, native details disclosures.
- No long scroll-jacking section, custom cursor, always-running marquee, continuously animated paths or repeated pointer listeners.
- Progressive reveals leave content visible if JavaScript is unavailable.
- Fonts bundled locally; no third-party runtime fetches.
- Server pre-rendered production HTML and generated metadata.

## Source content classification

The source business is Diligence. Agency content describes process automation, integrations, custom business systems and maintenance. These cannot be assumed to be cafe services. `hello@example.com`, project names and social destinations are placeholders. Shahdara, Delhi belongs to the agency footer and is not verified for the cafe. No cafe contact data or services were provided. The original remains intact in this directory; the cafe project uses explicit placeholders as requested.

No printing, scanning, form-filling, photocopying, computer rental, pricing, opening-time promises, testimonials, awards or cafe history have been invented.
